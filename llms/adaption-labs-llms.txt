# Adaption Labs

> Adaption Labs builds adaptive AI systems that continuously learn from real-world
> interaction rather than scaling through ever-larger pretraining. Its Adaptive Data
> platform and Adaption API let teams ingest, adapt, evaluate, and export model-ready
> training data; AutoScientist automates the research loop behind model training and
> alignment. Founded 2025 by Sara Hooker and Sudip Roy (ex-Cohere). San Francisco.

## SDK

- [Python SDK (PyPI: adaption)](https://pypi.org/project/adaption/): `pip install adaption`. Official, Apache-2.0. Sync `Adaption` and async `AsyncAdaption` clients.

## Lifecycle

The API and SDK expose one lifecycle over dataset resources: ingest -> adapt -> evaluate -> export.

- Ingest: upload a local file (csv/json/jsonl/parquet) via presigned upload, or import from Hugging Face or Kaggle.
- Adapt: start an adaptation run against a dataset; runs execute asynchronously (poll status / wait for completion).
- Evaluate: retrieve dataset evaluation results.
- Export: download the adapted dataset.
