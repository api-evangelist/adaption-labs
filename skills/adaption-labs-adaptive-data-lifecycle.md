# Adaptive Data lifecycle

Run the full Adaptive Data lifecycle — **ingest -> adapt -> evaluate -> export** —
with the official Adaption Python SDK. Every method below is a real method on the
published `adaption` client (verified against SDK 0.4.0); paths are namespaced under
`/api/v1`. This skill was generated by the API Evangelist enrichment pipeline.

## Prerequisites

- `pip install adaption`
- An API key from the Adaption app (Settings > API keys). Export it:
  `export ADAPTION_API_KEY="pt_live_..."`
- Auth is HTTP Bearer (`Authorization: Bearer pt_live_...`). See
  `authentication/adaption-labs-authentication.yml`.

## Steps

1. **Construct the client.**
   ```python
   from adaption import Adaption
   client = Adaption()  # reads ADAPTION_API_KEY
   ```

2. **Ingest** a dataset (returns a `dataset_id`). Choose one path:
   - Local file (csv/json/jsonl/parquet) via presigned upload:
     `result = client.datasets.upload_file("training_data.csv")`
   - Hugging Face:
     `client.datasets.create_from_huggingface(url="https://huggingface.co/datasets/org/repo", files=["train.csv"])`
   - Kaggle (register Kaggle creds under Settings > API keys first):
     `client.datasets.create_from_kaggle(url="https://www.kaggle.com/datasets/org/dataset-name", files=["data.csv"])`
   Imports run asynchronously — call `client.datasets.wait_for_completion(dataset_id)`
   before adapting.

3. **Adapt.** Start an adaptation run against the dataset:
   `client.datasets.run(dataset_id, ...)`. Runs execute asynchronously.

4. **Wait / poll.** Block until the run finishes:
   `client.datasets.wait_for_completion(dataset_id)` (or poll
   `client.datasets.get_status(dataset_id)`).

5. **Evaluate.** Inspect quality:
   `client.datasets.get_evaluation(dataset_id)`.

6. **Export.** Download the adapted dataset:
   `client.datasets.download(dataset_id)`.

## Conventions & error handling

- Long-running work is asynchronous: always reach a completed status (step 4)
  before moving to the next stage. See `conventions/adaption-labs-conventions.yml`.
- No idempotency-key header is documented; do not assume safe automatic retries of
  create/run without checking status first.
